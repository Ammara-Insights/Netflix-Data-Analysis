# Netflix Content Analysis

## Project Overview

Netflix has a vast and constantly evolving library of movies and TV shows. This project analyzes Netflix content data to uncover patterns in content growth, genres, ratings, countries, and release trends.

The analysis transforms raw Netflix data into meaningful insights using data cleaning, transformation, and interactive visualization. The goal is to understand how Netflix's content library has evolved and identify the key patterns shaping its catalog.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization
- Dashboard Design

## Objectives

- Analyze the distribution of Movies and TV Shows
- Explore Netflix content growth over time
- Identify popular genres and content categories
- Analyze content by country
- Understand rating distribution
- Identify trends in Netflix's content library
- Present insights through an interactive dashboard
